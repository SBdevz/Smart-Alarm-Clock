# Smart Alarm Clock

This is a smart alarm clock that uses an ESP32 to control the system.

It includes an OLED display that shows weather conditions and temperature, a buzzer that sounds an alarm, and a button for settings.

Right now, there is a basic schematic of the PCB and a small program in this repository. The project is a work in progress, so I will make final changes when the PCB arrives!

Stay tuned for more progress. Thank you!
